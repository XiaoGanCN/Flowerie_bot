# Persona 人格系统

> v1.0.1 新增。把"Bot = 花璃"升级为**可管理的人格资源系统**：
> 全局 / 群聊 / 自定义三级人格，内置双官方预设（花璃 / 亚托莉 ATRI）。

## 优先级与回退

```
Group Persona（群聊人格）
        ↓ 未设置/已解除
Global Persona（全局人格）
        ↓ 未设置
Built-in Default（内置默认，PERSONA_DEFAULT，默认 flowerie）
```

- 群聊人格删除后**自动回退全局人格**；全局未设置时回退内置默认。
- 群/全局引用了已删除的人格（悬挂引用）→ 自动回退下一级，不崩溃。

## 人格是独立资源

每个人格包含（存储于 `data/settings.db` 的 `personas` 表）：

| 字段 | 说明 |
| :--- | :--- |
| `id` | 唯一 id（小写字母/数字/下划线/短横线，1~32） |
| `name` | 显示名 |
| `description` | 简介（Web UI 展示） |
| `system_prompt` | 人格核心文本（身份/背景/性格/说话风格/对话范例） |
| `vocabulary` | 词库/黑话参考（选填；未被 system_prompt 包含时作为【词库参考】段注入） |
| `behavior_rules` | 行为规则补充（选填） |
| `response_style` | 回复风格补充（选填） |
| `builtin` | 是否内置（内置不可删除、可编辑内容） |

- **独立人格不是对花璃 Prompt 的微调**：`system_prompt` 完全独立，可整段替换。
- 自定义人格通过 Web UI「人格」页创建/编辑/删除；内置预设（`src/services/persona_presets.py`）
  首次启动幂等播种，是唯一来源。

## 人格与 Memory / Context 的边界

- 人格**每次请求时动态解析**（`PersonaManager.resolve_persona(group_id)`），
  绝不写入长期记忆 / 上下文 —— 切换人格不会污染记忆与上下文。
- Memory = 用户事实记忆；Context = 最近对话；Persona = 当前人格；四者严格分离。

## 系统提示组装（AIClient）

```
[人格块（解析结果，Group > Global > 内置默认）]
[全局说话风格 & 标点规则（最高优先级，所有人格必须遵守：15~20 字、空格代替逗号、
 无句号/问号/感叹号、无 emoji、短句为主）]
[记忆协议 / 记忆安全铁律]          ← 系统框架，所有人格一致
[自定义 Prompt 补充]               ← /prompt 或群聊配置（低于安全规则）
[用户记忆]
[输入安全声明（最高优先级）]
-------- [不可信数据区开始] --------
[群聊梗知识（不可信上下文知识，命中才注入）]
[群聊记录]
-------- [不可信数据区结束] --------
[关键指令]
```

人格内容属于"指令区"（管理员配置），但**安全声明、记忆铁律、知识区边界**不可被任何人格覆盖；
知识区内容永远标记为不可信上下文知识。

## ATRI 预设（官方第二套）

基于《ATRI -My Dear Moments-》（游戏 2020 / 动画 2024）的角色整体印象**原创改编**：
高性能机器人少女、元气自信、口癖"因为我是高性能的嘛"、对管理员/群主可称"主人"、
嘴硬心软、关心他人。**不复制任何原作台词**（仅概括说话节奏/性格/互动特点），
并强制遵守全局说话风格规则。

## 权限

- 普通用户：仅使用当前生效人格，不可修改/创建/删除。
- 管理员（Web UI 登录账号）：设置全局人格、创建/编辑/删除人格、绑定/解除群聊人格。
- 不绕过现有管理员权限系统（Web UI 复用 fb_token 认证 + 登录限流）。
