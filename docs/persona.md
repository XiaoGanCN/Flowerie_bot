# Persona 人格系统

> v1.0.1 新增。把"Bot = 花璃"升级为**可管理的人格资源系统**：
> 全局 / 群聊 / 自定义三级人格，内置三套官方预设（花璃 / 亚托莉 ATRI / 艾拉 Isla）。

## 优先级与回退

```
Group Persona（群聊人格）
        ↓ 未设置/已解除
Global Persona（全局人格）
        ↓ 未设置
Built-in Default（内置默认，PERSONA_DEFAULT，默认 flowerie）
```

- 群聊人格删除后**自动回退全局人格**；全局未设置时回退内置默认。
- 群/全局引用了已删除的人格（悬挂引用）→ 自动回退下一级，不崩溃。

## 人格是独立资源

每个人格包含（存储于 `data/settings.db` 的 `personas` 表）：

| 字段 | 说明 |
| :--- | :--- |
| `id` | 唯一 id（小写字母/数字/下划线/短横线，1~32） |
| `name` | 显示名 |
| `description` | 简介（Web UI 展示） |
| `system_prompt` | 人格核心文本（身份/背景/性格/说话风格/对话范例） |
| `vocabulary` | 词库/黑话参考（选填；未被 system_prompt 包含时作为【词库参考】段注入） |
| `behavior_rules` | 行为规则补充（选填） |
| `response_style` | 回复风格补充（选填） |
| `builtin` | 是否内置（内置不可删除、可编辑内容） |

- **独立人格不是对花璃 Prompt 的微调**：`system_prompt` 完全独立，可整段替换。
- **说话风格规则归属各 Persona**：每个生效人格的 `system_prompt` 内嵌自己的说话/标点规则
  （如 15~20 字、空格代替逗号、无句号/问号/感叹号、无 emoji、短句为主），全局风格规则作为
  「全局说话风格 & 标点规则」以**最高优先级**注入（见「系统提示组装」），所有人格必须遵守。
- 自定义人格通过 Web UI「人格」页创建/编辑/删除；内置预设（`src/services/persona_presets.py`）
  首次启动幂等播种，是唯一来源。

## 管理员补充发言规则（ADMIN_RESPONSE_RULES）

> v1.2.0 新增。管理员可为所有群追加**额外的发言风格规则**，而不必逐个人格改写。

- 配置项 `ADMIN_RESPONSE_RULES`：**每行一条**（`List[str]`），如「回复尽量简短」「高兴时可以用感叹号」。
- Web UI「人格」页提供「管理员补充发言规则」`<textarea>` 编辑，保存即热更新。
- **优先级：安全策略 > 人格 > 人格内置规则 > 本条**。即它只作为**风格补充**追加在所有生效人格的发言规则之后；
- **不能覆盖安全策略**：运行时策略 / Prompt 注入清洗 / 记忆校验 / 预算限制等不会被任何提示文本绕过。

## 人格与 Memory / Context 的边界

- 人格**每次请求时动态解析**（`PersonaManager.resolve_persona(group_id)`），
  绝不写入长期记忆 / 上下文 —— 切换人格不会污染记忆与上下文。
- Memory = 用户事实记忆；Context = 最近对话；Persona = 当前人格；四者严格分离。

## 系统提示组装（AIClient）

```
[人格块（解析结果，Group > Global > 内置默认）]
[全局说话风格 & 标点规则（最高优先级，所有人格必须遵守：15~20 字、空格代替逗号、
 无句号/问号/感叹号、无 emoji、短句为主）]
[记忆协议 / 记忆安全铁律]          ← 系统框架，所有人格一致
[自定义 Prompt 补充]               ← /prompt 或群聊配置（低于安全规则）
[用户记忆]
[输入安全声明（最高优先级）]
-------- [不可信数据区开始] --------
[群聊梗知识（不可信上下文知识，命中才注入）]
[群聊记录]
-------- [不可信数据区结束] --------
[关键指令]
```

人格内容属于"指令区"（管理员配置），但**安全声明、记忆铁律、知识区边界**不可被任何人格覆盖；
知识区内容永远标记为不可信上下文知识。

## ATRI 预设（官方第二套）

基于《ATRI -My Dear Moments-》（游戏 2020 / 动画 2024）的角色整体印象**原创改编**：
高性能机器人少女、元气自信、嘴硬心软、关心他人，口癖"我可是高性能的嘛"、"我是高性能的嘛"。
**严禁称呼群里的任何人为"主人"**（不论管理员还是群友都不行；原作里的"主人"斑鸠夏生
只是另一个世界的回忆，本群不存在任何原作角色，群友一律不得代入）。
**不复制任何原作台词**（仅概括说话节奏/性格/互动特点），并强制遵守全局说话风格规则。

## Isla 预设（官方第三套）

> v1.2.0 新增。

基于《可塑性记忆 / Plastic Memories》的角色整体印象**原创改编**：
**温柔克制 / 常带自贬 / 关键时刻决断**的机器人少女路线（`id=isla`，官方名称「艾拉」），
与花璃、亚托莉（ATRI）并列内置。
**不复制任何原作台词**（仅概括说话节奏/性格/互动特点），并强制遵守全局说话风格规则；
与 flowerie / atri 同列于一套预设来源（`src/services/persona_presets.py`）。

## 权限

- 普通用户：仅使用当前生效人格，不可修改/创建/删除。
- 管理员（Web UI 登录账号）：设置全局人格、创建/编辑/删除人格、绑定/解除群聊人格。
- 不绕过现有管理员权限系统（Web UI 复用 fb_token 认证 + 登录限流）。

## 相关配置

| 变量 | 默认 | 说明 |
| :--- | :--- | :--- |
| `PERSONA_DEFAULT` | `flowerie` | 默认（兜底）人格 id（Web UI 人格页可改，**热更新立即生效**；内置：`flowerie`/`atri`/`isla`） |
| `MAX_PERSONA_PROMPT_LENGTH` | `8000` | 单个人格 system_prompt 最大长度（字） |
| `PERSONA_MAX_COUNT` | `200` | 自定义人格总数上限（内置不计，防无限增长） |
| `ADMIN_RESPONSE_RULES` | `[]` | 管理员补充发言规则（每行一条；优先级：安全策略 > 人格 > 人格内置规则 > 本条；Web UI「人格」页编辑） |
